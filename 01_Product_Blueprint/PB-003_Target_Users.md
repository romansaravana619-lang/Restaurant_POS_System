# Purpose

This document defines the primary users of Saru POS, their responsibilities, goals, and expectations. Understanding the target users helps design a system that is simple, secure, and efficient for daily restaurant operations.

---

# Primary Users

Saru POS is designed for three primary user roles:

- Restaurant Owner
- Restaurant Manager
- Staff

Each user has different responsibilities and requires different levels of system access.

---

# User 1 – Restaurant Owner

## Description

The restaurant owner is responsible for managing the overall business and monitoring its performance.

## Responsibilities

- View business reports
- Monitor daily sales
- Track profit and expenses
- Manage employees
- Manage menu items
- Monitor inventory
- Make business decisions

## Goals

- Increase business profitability
- Reduce operational problems
- Access business information quickly
- Improve overall restaurant efficiency

---

# User 2 – Restaurant Manager

## Description

The manager supervises daily restaurant operations and ensures smooth workflow between employees.

## Responsibilities

- Monitor daily operations
- Manage staff activities
- Verify sales records
- Handle customer issues
- Update menu availability
- Monitor inventory status

## Goals

- Ensure smooth restaurant operations
- Reduce operational delays
- Improve customer satisfaction
- Maintain accurate daily records

---

# User 3 – Cashier

## Description

The cashier handles customer billing and payment transactions.

## Responsibilities

- Create customer bills
- Process payments
- Print invoices
- Search previous bills
- Handle order modifications
- Maintain billing accuracy

## Goals

- Complete billing quickly
- Reduce billing errors
- Provide faster customer service
- Handle peak-hour transactions efficiently

---

# Common User Expectations

All users expect the system to be:

- Easy to learn
- Fast to use
- Reliable during business hours
- Accurate in calculations
- Secure for business data

---

# User Access Summary

| User | Primary Responsibility | Access Level |
|------|------------------------|--------------|
| Admin | Complete Business Management | Full Access |
| Manager | Daily Operations Management | Medium Access |
| Staff | Billing Operations | Limited Access |

---

# Design Considerations

While designing Saru POS, the system should:

- Display only relevant features for each user.
- Prevent unauthorized access to sensitive business data.
- Keep the interface simple and user-friendly.
- Minimize the number of steps required to complete daily tasks.
- Ensure fast response time during busy restaurant hours.
