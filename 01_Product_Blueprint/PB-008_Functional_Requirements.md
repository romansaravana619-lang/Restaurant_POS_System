# Purpose

This document defines the functional requirements of Saru POS. Functional requirements describe what the system must do to meet business needs and user expectations.

---

# Authentication Requirements

| ID | Requirement |
|----|-------------|
| FR-001 | The system shall allow users to log in using a username and password. |
| FR-002 | The system shall validate user credentials before granting access. |
| FR-003 | The system shall provide role-based access based on the logged-in user. |
| FR-004 | The system shall allow users to securely log out. |

---

# Dashboard Requirements

| ID | Requirement |
|----|-------------|
| FR-005 | The system shall display a dashboard after successful login. |
| FR-006 | The dashboard shall display today's sales summary. |
| FR-007 | The dashboard shall provide quick access to major modules. |

---

# Billing Requirements

| ID | Requirement |
|----|-------------|
| FR-008 | The system shall allow users to create a new bill. |
| FR-009 | The system shall calculate the total bill automatically. |
| FR-010 | The system shall generate an invoice after payment. |
| FR-011 | The system shall allow searching previous bills. |
| FR-012 | The system shall store every completed transaction. |

# Acceptance Criteria

The functional requirements will be considered complete when:

- All core business operations are covered.
- Every requirement has a unique ID.
- Each requirement is testable.
- Requirements align with the product scope.
