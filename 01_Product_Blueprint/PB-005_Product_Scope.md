# Purpose

This document defines the scope of Saru POS Version 1.0. It clearly identifies what is included, what is excluded, and the planned future enhancements.

---

# Product Scope

Saru POS Version 1.0 is designed to provide essential restaurant management features for medium-sized family restaurants through a web-based application.

The system focuses on improving daily operations without unnecessary complexity.

# Out of Scope (Version 1.0)

The following features will NOT be included in Version 1.0:

- AI Sales Analysis
- Multi-Branch Management
- Cloud Synchronization
- Swiggy Integration
- Zomato Integration
- Kitchen Display System (KDS)
- QR Code Ordering
- Online Ordering
- SMS Notifications
- Email Marketing
- Customer Loyalty Program

# Scope Boundaries

The primary objective of Version 1.0 is to deliver a stable, reliable, and easy-to-use restaurant management system.

Additional advanced features will only be introduced after the successful completion and validation of the core system.

---

# Assumptions

- Restaurants have internet access.
- Users have basic computer knowledge.
- The system will be used through a modern web browser.
- SQLite is sufficient for Version 1.0.

---

# Constraints

- Single restaurant support only.
- English language interface.
- Web application only.
- One-time licensing model.

---

# Success Criteria

The scope will be considered complete when all Version 1.0 features are fully implemented, tested, and documented without introducing out-of-scope functionality.
