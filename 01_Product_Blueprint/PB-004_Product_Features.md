# Purpose

This document defines the core features of Saru POS. These features represent the primary capabilities required to manage restaurant operations efficiently and will serve as the foundation for system design and development.

---

# Feature Categories

The features of Saru POS are organized into functional modules.

---

# Module 1 – User Authentication

## Features

- Secure login system
- Role-based access (Owner, Manager, Cashier)
- Password management
- Logout functionality

---

# Module 2 – Dashboard

## Features

- Daily sales summary
- Today's orders
- Revenue overview
- Quick navigation to major modules
- Business statistics cards

---

# Module 3 – Billing Management

## Features

- Create new bill
- Edit bill before payment
- Delete cancelled bill (authorized users)
- Generate invoice
- Print receipt
- Search previous bills

---

# Module 4 – Menu Management

## Features

- Add menu items
- Edit menu items
- Delete menu items
- Organize menu by category
- Update item prices
- Enable or disable menu items

---

# Module 5 – Customer Management

## Features

- Add customer details
- View customer history
- Search customers
- Maintain repeat customer records

---

# Module 6 – Inventory Management

## Features

- Add inventory items
- Update stock quantity
- Monitor stock availability
- Low-stock alerts (future enhancement)
- View inventory list

---

# Module 7 – Sales Reports

## Features

- Daily sales report
- Weekly sales report
- Monthly sales report
- Revenue summary
- Best-selling items
- Sales history

---

# Module 8 – Employee Management

## Features

- Employee list
- Employee information
- Assign user roles
- Manage system access

---

# Module 9 – System Settings

## Features

- Restaurant profile
- Change password
- User management
- System configuration
- Backup settings (future)

---

# Future Features (Version 2 & 3)

- Kitchen Display System (KDS)
- Swiggy Integration
- Zomato Integration
- QR Code Ordering
- AI Sales Analysis
- Smart Inventory Prediction
- Multi-Branch Management
- Cloud Synchronization

# Success Criteria

The feature set is considered complete when:

- All core restaurant operations are covered.
- Features are organized into logical modules.
- Every module supports the product vision.
- Future expansion is possible without major redesign.
