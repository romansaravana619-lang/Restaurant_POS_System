# 1. Purpose

This document serves as the master index for all Entity Relationship (ER) Diagram documentation of the Saru POS project.

It provides a structured overview of every ER-related document, including entity definitions, relationship specifications, and the final database blueprint.

This index acts as the central navigation point for the complete database modeling documentation.

---

# 2. Objectives

The objectives of this document are:

- Maintain a centralized index of all ER documentation.
- Organize entity and relationship documents.
- Provide version control for ER diagrams.
- Improve documentation readability and maintainability.
- Support future database enhancements.
- Ensure consistency across all database design documents.
