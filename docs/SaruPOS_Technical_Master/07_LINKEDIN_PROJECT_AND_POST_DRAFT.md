## Project title
**SaruPOS — Full-Stack Restaurant Point of Sale System**

## Project description
Built and completed a full-stack Restaurant POS using React, Vite, Python, Flask, REST-style APIs and SQLite, with JWT authentication, Argon2 password hashing and RBAC.

## Technical highlights
React/Vite; Python/Flask; REST API; SQLite; JWT; Argon2; RBAC; customer/table/dining-session workflows; POS/cart; server-side checkout validation; atomic billing/payment workflow; inventory; suppliers; receipt flow; POS draft persistence; API/security and manual E2E validation.
